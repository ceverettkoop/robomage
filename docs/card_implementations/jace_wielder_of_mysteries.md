# Jace, Wielder of Mysteries

## Oracle text
If you would draw a card while your library has no cards in it, you win the game instead.
- [+1]: Target player mills two cards. Draw a card.
- [-8]: Draw seven cards. Then if your library has no cards in it, you win the game.

- Mana cost: {1}{U}{U}{U}
- Type: Legendary Planeswalker — Jace
- Starting loyalty: 4

## Engine work

Mechanics added (general): **draw-empty-win-replacement** (CR 104.3a / 121.4).

The engine hard-coded draw-from-empty-library = LOSS in `Orderer::perform_draw`. Jace needs a
replacement on that specific event so YOU win instead.

- `src/components/effect.h` — new `Effect::Replacement::DRAW_EMPTY_WIN` kind.
- `src/parse.cpp:parse_replacement_effects` — parses `R:Event$ Draw | ... | ReplaceWith$ Win`
  into a `DRAW_EMPTY_WIN` replacement, confirming the `ReplaceWith$` SVar body is a `DB$ WinsGame`
  (rather than retagging the R: line). Scoped to the controller (`ValidPlayer$ You`).
- `src/systems/orderer.cpp:perform_draw` — at the empty-library draw site, before declaring the
  deck-out loss, scans the drawing player's battlefield permanents for a live `DRAW_EMPTY_WIN`
  replacement; if found, that player WINS instead (sets `cur_game.winner`/`ended`, mirroring the
  existing `effects::wins_game` outcome). Without such a replacement the default deck-out loss is
  unchanged.
- The loyalty +1 (Mill target player + Draw) and -8 (Draw 7 + conditional WinsGame) use
  already-covered effects (Mill, Draw, WinsGame) and the existing planeswalker loyalty machinery
  (loyalty storage/cost/activation) — verified working, no new engine code.
- `src/card_vocab.h` — `{"Jace, Wielder of Mysteries", 333}`; `train/card_costs.py` +
  `src/gen/card_costs_gen.h` regenerated by `make`.

## Behavioral decisions
- The win replaces the empty-library draw event directly at the draw site (where the engine
  models the deck-out), matching CR 104.3a/121.4 outcome. It is controller-scoped: only the Jace
  controller's own empty-library draw wins; the opponent decking out still loses normally.
- General: any card with an `Event$ Draw ... ReplaceWith$ <WinsGame SVar>` replacement (e.g.
  Laboratory Maniac-style) reuses this path.

  Draw/WinsGame effects.)
