# Prismatic Ending

## Oracle text
Converge — Exile target nonland permanent if its mana value is less than or equal to the number
of colors of mana spent to cast this spell.

- Mana cost: {X}{W}
- Type: Sorcery

## Engine work

Mechanics added (general): **converge** (CR 702.90).

Converge = track the SET of distinct colors of mana actually SPENT to cast a spell, expose it as
`Count$Converge`, and feed it as the dynamic `cmcLE` bound Y in the target-condition gate.

- **Spent-color capture** — `src/mana_system.cpp`: `pay_from_pool` gained an optional
  `ManaValue *spent` out-parameter recording each color erased from the pool; `spend_mana` /
  `pay_partial` / `auto_pay_mana` (its inline per-pip pool erases, commit-mode only) route the
  colors into a module-static sink `s_mana_spent_sink`. `prompt_mana_payment` gained an optional
  `ManaValue *spent_out`; it arms the sink for the duration of the (blocking) payment via a RAII
  guard, so dry-run affordability checks — which route through `pay_from_pool` on pool COPIES with
  a null `spent` — never pollute it. This captures colors even in the tap-then-consume case (a
  source tapped and immediately spent during payment) that a before/after pool diff would miss.
- **Cast flow** — `src/action_processor.cpp`: `Game::PendingCast::mana_spent_colors` accumulates
  the payment's spent colors (passed to `prompt_mana_payment` at the deferred `MANA_PAY` step and
  the alt-cost path). At `FINISH` the distinct real colors (WHITE..GREEN; colorless is not a
  color) are copied onto `Spell::colors_spent` (`src/components/spell.h`).
- **Resolution** — `src/systems/stack_manager.cpp`: restores `cur_game.converge` from the
  resolving `Spell::colors_spent.size()` (mirrors the `x_paid` restore) so a `Count$Converge`
  bound reads THIS spell's value.
- **Count$Converge** — `src/components/ability.cpp:evaluate_dynamic_amount` resolves it to
  `cur_game.converge`; `src/parse.cpp` recognizes `Count$Converge` when resolving the `cmcLEY`
  condition SVar into `dynamic_amount_expr` (via the existing `condition_present` cmcLE→amount_svar
  path).
- **Exile gate** — `src/effects/effect_change_zone.cpp`: the targeted battlefield→exile move now
  honors `ConditionDefined$ Targeted` with a dynamic cmcLE bound — it evaluates the threshold
  (Converge) and skips a target whose mana value exceeds it (CR 608.2b: enforced at resolution;
  cast legality does not gate on `condition_on_target`). General to any targeted ChangeZone whose
  `ConditionPresent` carries a `cmcLE<svar>` threshold.
- `src/card_vocab.h` — `{"Prismatic Ending", 338}`; `train/card_costs.py` +
  `src/gen/card_costs_gen.h` regenerated by `make`.

## Converge color-set field/API (for future cards)
- `Spell::colors_spent` (`std::set<Colors>`) — distinct real colors of mana spent to cast the
  spell; its size is Converge.
- `Game::PendingCast::mana_spent_colors` (`ManaValue`) — per-cast accumulator, sibling of the
  existing `mana_spent` pip COUNT; populated by the payment's spent-color sink.
- `cur_game.converge` (`int`) — Converge of the spell currently resolving; sibling of
  `cur_game.x_paid`. Read via `Count$Converge`.
- `prompt_mana_payment(..., ManaValue *spent_out)` — pass an accumulator to collect the exact
  colors spent by any mana payment.

## Behavioral decisions
- Converge counts DISTINCT real colors (WHITE..GREEN). Colorless mana is not a color (CR 105.1)
  and is excluded, as is any generic-pip artifact.
- The `{X}` in `{X}{W}` is the generic scaler; it does not itself raise Converge — spending the
  generic pips with DIFFERENT colors does. `Count$xPaid` (X) is unused by the exile threshold,
  which reads `Count$Converge`.
