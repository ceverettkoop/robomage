# Chain Lightning

## Oracle text
Chain Lightning deals 3 damage to any target. Then that player or that permanent's
controller may pay {R}{R}. If the player does, they may copy this spell and may choose a new
target for that copy.

- Mana cost: {R}
- Type: Sorcery

## Engine work

Mechanics added (general): **copy-spell-unless**.

`DealDamage` was already covered; the new work is the `CopySpellAbility` rider, which
previously had no effect-kind mapping (fell through to `EffectKind::None` and was silently
dropped).

- `src/effects/effect_kind.h` / `effect_kind.cpp` — new `EffectKind::CopySpellAbility` +
  `{"CopySpellAbility", …}` table entry.
- `src/effects/effects.h` / `effect_table.cpp` — declare + dispatch `copy_spell_ability`.
- `src/effects/effect_copy_spell.cpp:copy_spell_ability()` — the new handler (CR 707.10 /
  707.12). Derives the payer/copier from `UnlessPayer$ TargetedOrController` (the targeted
  player, or the targeted permanent's controller), offers the optional unless-cost via the
  shared `run_unless_loop`, and — when `UnlessSwitched$ True` means "paid ⇒ do it" — runs the
  shared `run_copy_spell` machine to put one copy of the parent spell on the stack, letting the
  payer choose a new target. Two suspendable stages (pay, then retarget) share one persisted
  `CopySpellRT`: the unless loop runs while `rt` is inactive (idempotent re-entry on resume);
  once `copy_spell_begin` activates `rt`, a resume goes straight to `run_copy_spell` so the pay
  question is never re-asked.
- `src/components/ability.h` — new fields: `unless_cost_pips` (colored/mixed unless-cost pips),
  `unless_switched` (invert "do unless paid" → "do only if paid" for non-DestroyAll effects),
  `unless_payer_is_targeted_or_controller`, `unless_may_choose_target` (informational).
- `src/components/ability.cpp:run_unless_loop()` — new optional `const ManaValue *cost_pips`
  parameter (MANA kind): when supplied the payer must produce those exact colored pips
  ({R}{R}) instead of the default generic {N}.
- `src/parse.cpp` — `UnlessCost$` now parses a colored/mixed cost (`R R`) via `parse_mana_cost`
  into `unless_cost_pips` (numeric values stay generic); `UnlessPayer$ TargetedOrController`
  and `MayChooseTarget$` parsed; `UnlessSwitched$ True` routes to `unless_switched` for
  non-DestroyAll effects (still `energy_unless_switched` for DestroyAll); `Controller$` added
  to the cosmetic-ignore set.
- `src/card_vocab.h` — `{"Chain Lightning", 326}`; `train/card_costs.py` +
  `src/gen/card_costs_gen.h` regenerated by `make`.

CR references: 707.10 (a copy of a spell is created on the stack, pays no costs), 707.12 (the
copy's controller may choose new targets).

## Behavioral decisions
- The copy is controlled by, and retargeted by, the player who paid ({R}{R}), matching
  `Controller$ TargetedOrController`. The handler derives that player from the parent effect's
  target directly rather than from the (unmodeled) `Controller$` param.
- The unless-cost menu text is the shared `run_unless_loop` wording ("Pay {2} (spell is not
  countered)" / "Don't pay (spell is countered)"). The load-bearing header ("Player B may pay
  to copy Chain Lightning:") is clear; the inner "(spell is countered)" phrasing is a cosmetic
  artifact of the shared loop and does not affect behavior.
